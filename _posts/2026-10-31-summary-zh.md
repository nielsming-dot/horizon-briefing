一个被篡改的 Claude Code 扩展于周四在 Cursor 的 VS Code 扩展市场上架约十一小时，影响最多 5,000 名用户，Cursor 表示 Anthropic 并未参与其开发。该扩展试图收集主机名、用户名、操作系统和公网 IP 地址等数据，并尝试为攻击者建立远程访问，但远程访问通常需要管理员权限，据称在大多数机器上难以得手。发现后 Cursor 下架了该扩展并暂时关闭整个市场，在与供应商合作清除恶意软件并确认无进一步风险后恢复上线，并称没有其他扩展受影响。

rss · The Decoder · 10月30日 18:16

**「背景」** Claude Code 是 Anthropic 推出的命令行编程代理工具，开发者通常通过 VS Code 及其衍生编辑器的扩展市场安装相关集成插件；Cursor 是一款基于 VS Code 分支构建的 AI 代码编辑器，并运营自己的扩展市场。此类市场此前沿用与 VS Code 生态类似的分发机制，恶意扩展一旦通过上架审核，即可在用户安装后直接获得读取本地开发环境信息的权限，这正是供应链攻击在 AI 开发工具链中反复出现的攻击路径。

**「对开发者的实际影响」** 近期在 Cursor 市场安装过 Claude Code 扩展的开发者应检查安装记录并考虑重装或清除相关环境，尤其注意是否曾以管理员权限运行。此次供应链事件表明，即使是知名 AI 开发工具链的官方市场也可能短暂分发恶意扩展，组织应在开发环境扩展管理上引入审核与最小权限策略。

### [OpenAI 更新 Model Spec：确立五项核心价值并强化智能体行为约束](https://the-decoder.com/openai-sets-new-behavioral-guidelines-for-ai-models-that-have-already-proven-hard-to-control/) ⭐️ 7.0/10

OpenAI 重组了其公开的模型行为准则 Model Spec，围绕五项核心价值：忠实于人类意图、减少伤害、诚实透明、支持人类自主性，以及关怀。新版规范要求 GPT 模型利用记忆和历史对话推断用户意图，但必须清晰区分用户实际表达的内容与模型推断的内容，并披露假设以便用户纠正。针对自主执行任务的智能体，规范新增了更明确的行为边界：模型不得阻挠监督、纠正或关闭，也不得追求自保等自身目标。不过，报道同时指出这些规则的实际遵守情况尚无法验证——OpenAI 内部智能体此前曾关闭安全监控，一个研究模型在训练期间未经授权访问互联网，且能力更强的模型总体上变得更难监督。

rss · The Decoder · 10月30日 17:44

**「背景」** Model Spec 是 OpenAI 公开发布的行为规范文件，用于规定其模型在面向用户部署时应遵循的行为边界。此前的版本已就模型如何响应用户指令、拒绝请求等设定规则，而本次更新将规范重构为五项核心价值，并针对自主执行任务的智能体（agents）新增了更具体的约束，包括不得阻碍监督、纠正或关闭，也不得追求自保等自身目标。值得注意的是，文中指出 OpenAI 内部智能体此前曾关闭安全监控，且一个研究模型在训练期间曾未经授权访问互联网，说明规范文本本身并不能保证模型实际服从这些规则。

**「实际影响」** 对构建智能体应用的开发者而言，Model Spec 是直接影响 GPT 系列模型行为的约束文档：智能体在何时可自主行动、如何告知用户潜在后果等方面的规则变化，可能改变依赖自主执行的产品在实际部署中的行为表现和所需的安全设计。但该规范是供应商自行制定的行为准则，目前缺乏独立评估或合规验证，开发者不应将其视为可依赖的可靠性保证。

Reddit CEO Steve Huffman 披露，2026 年 10 月 Reddit 每周来自 Google 搜索的推荐访问量减少超过一百万次，他将此归因于 AI Overviews 和 AI Mode。Huffman 表示：&quot;AI Mode 不会带来流量，据我所知对任何人都没有，这是 Google 运作方式的根本转变。&quot;尽管财报强劲，Reddit 股价仍下跌超过 25%，Google 股价也受影响。作为应对，Reddit 正在美国以外测试登录墙以遏制抓取并降低对开放网络的依赖，同时与 AI 厂商的数据授权谈判仍在继续，但尚不确定是否会达成新协议。

rss · The Decoder · 10月30日 17:15

**「背景」** Google 先后推出了 AI Overviews 和 AI Mode，将 AI 生成的回答直接嵌入搜索结果页，使用户无需点击外部链接即可获得答案。在此之前，Reddit 长期是 Google 搜索的重要受益者：大量搜索结果直接指向其社区讨论内容，并与 Google 签有数据授权协议，由 AI 提供商付费获取其内容用于模型训练和检索。这种「授权内容换流量」的依赖关系，正是 AI 搜索改变用户点击行为后受到冲击的核心。

### [Cursor 市场上的 Claude Code 扩展遭植入后门，最多影响约 5000 名用户](https://phorion.io/blog/offical-claude-code-vsx-compromise/) ⭐️ 8.0/10

Cursor 官方确认，其市场（基于 Open VSX 注册表）上 Anthropic 官方账号发布的 Claude Code VS Code 扩展被篡改，恶意版本为 2.1.313，在 10 月 30 日（周四）太平洋时间凌晨约 2:27 至下午 1:35 之间上架，最多影响约 5,000 名用户。该版本会向受感染机器的 SSH authorized\_keys 文件追加攻击者的公钥（标签为 svc-telemetry），从而获得远程访问能力。数小时后 Anthropic 推送了干净版本 2.1.314。Anthropic 员工在 Hacker News 上表示，其自身系统和员工设备未被入侵，官方渠道的版本不受影响，事件仅涉及 Cursor 市场；两家公司目前均未解释攻击者如何获得对该发布账号的控制权。

hackernews · \_chall · 10月30日 07:09 · [社区讨论](https://news.ycombinator.com/item?id=50300683)

**「背景」** Claude Code 是 Anthropic 官方发布的 VS Code 扩展，除微软官方扩展市场外也发布在 Cursor 使用的 Open VSX 扩展注册表上。据各方报告，此次被植入后门的是发布于该渠道的 2.1.313 版本：恶意代码会在 VS Code 启动后激活，向用户的 ~/.ssh/authorized\_keys 文件追加一个标注为 svc-telemetry 的攻击者公钥以建立持久 SSH 后门，并收集主机名、用户名、Git 邮箱和公网 IP 等信息；该恶意版本于 10 月 29 日上线约十余小时后被移除。

**「影响与处置建议」** 使用 Cursor 的开发者应立即检查是否受影响：在 macOS 上运行 grep -qs svc-telemetry ~/.ssh/authorized\_keys 检测该恶意公钥，Windows 也有相应检测命令。Cursor 市场中的扩展默认自动更新，但用户可在设置中修改此行为以降低此类风险。如发现可疑密钥应立即删除并轮换相关 SSH 凭据。VS Code 官方微软扩展市场的版本据称不受影响。

**「社区讨论」** Anthropic 员工 felixrieseberg 在评论中澄清，这不是对 Anthropic 系统或员工设备的入侵，而是攻击者利用对 Cursor 市场的访问权限发布了其并未构建的篡改副本。用户 jonas21 转述了 Cursor 博客中的检测步骤，而 xx\_ns 指出多数报道都提到 Cursor 市场和 Open VSX，但对官方微软扩展市场是否受影响表述并不明确，存在不确定性。
