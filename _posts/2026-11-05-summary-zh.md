hackernews · abrarthought · 11月4日 15:30 · [社区讨论](https://news.ycombinator.com/item?id=50366999)

**「背景」** Kimi K3.1 Pro 是 Moonshot AI（月之暗面）Kimi 系列的公开权重模型发布，托管在 Hugging Face 上。该团队此前以开放权重策略与官方 API 并行的路线闻名，这类发布通常会吸引第三方推理服务商快速接入。发布后的社区讨论围绕两个常见争议点展开：一是基准测试成绩是否夸大（即所谓 &quot;benchmaxxing&quot;），二是模型体积带来的自托管硬件门槛。

### [Go 官方推出实验性 JSON API encoding/json/v2](https://go.dev/blog/jsonv2) ⭐️ 8.0/10

Go 团队在官方博客上宣布了新的实验性 JSON API encoding/json/v2,这是对该语言中使用最广泛的标准库包之一的重大更新。该 API 目前处于实验阶段,尚未说明正式可用时间。官方文章同时介绍了其设计思路,社区讨论显示从 v1 迁移存在一些实际障碍,例如缺少 MarshalIndent 等常用便捷函数。

hackernews · olexsmir · 11月4日 17:52 · [社区讨论](https://news.ycombinator.com/item?id=50369106)

**「背景」** Go 的标准库 encoding/json 自 Go 1 发布以来一直是语言中使用最广泛的包之一,但其在自定义选项、性能和错误处理方面的设计限制由来已久,官方多年来也因此收到大量改进诉求。此次 Go 团队推出的 encoding/json/v2 是一个实验性新 API,旨在重新设计 JSON 的编码与解码接口,同时通过兼容层帮助现有代码逐步迁移,而不是直接替换旧包。

**「社区反馈」** 有使用者\(如 CamouflagedKiwi\)肯定了 encoding/json/v2 的整体设计,但抱怨其省去了 MarshalIndent,导致等价代码复杂难写、迁移困难;另有开发者 txomon 分享了在生产环境中使用其底层 jsontext 包构建容错解析器的经验,称其性能出色、值得推荐。这些是个人使用反馈,官方尚未回应相关 API 取舍的争议。

研究人员于周三报告称,一批与俄罗斯对外情报局有中度到高度置信度关联的攻击者,通过在多个被入侵网站\(包括美国建国 250 周年纪念组织 america250.org 的仿冒站点 america250\[.\]holiday\)注入 JavaScript,对访问者的 iPhone 和 Android 设备进行指纹识别,并投递针对各平台的定制化载荷。攻击利用的是此前已修复的 iOS 和 Android 漏洞,试图窃取浏览器 Cookie,部分情况下还会窃取 Wi-Fi 密码和完整的移动设备数据。被仿冒和攻击的许多网站与美国、乌克兰战争相关事务存在联系。

rss · Ars Technica · 11月4日 22:26

**「背景」** 水坑式攻击指攻击者在受害者常访问的网站上注入恶意代码,待其访问时自动探测设备并发起针对性利用。本次活动中,攻击者在 iPhone 上串联利用了 CVE-2025-43529 和 CVE-2024-27834 两个漏洞,从运行 iOS 16.7 的设备窃取浏览器 cookie,从而可能重放已登录会话、访问受害者的网页邮箱等服务;相关研究由 Lookout、Google 与 iVerify 联合完成,攻击工具被称为 DarkSword。

**「影响」** 由于攻击利用的是已修补漏洞,保持系统及时更新的用户风险较低;但浏览器 Cookie 一旦被窃取,攻击者可能借此接管相关会话,访问过被植入恶意代码网站的用户应检查设备更新状态并注意相关账户的异常登录。

### [OpenAI 团队披露约 948 个 Linux 内核提权漏洞](https://openai.com/index/a-thousand-fewer-paths-to-root/) ⭐️ 7.0/10

OpenAI 的一个安全团队公开披露了约 948 个 Linux 内核提权漏洞，标题称之为&quot;减少一千条获取 root 权限的路径&quot;。报告作者在 Hacker News 上确认这是其团队的工作成果，并表示愿意回答问题。披露的核心意义在于展示了 AI 辅助漏洞发现的规模：一次工作就找出近千条本地提权路径，远超传统人工审计的产出量。但根据现有信息，报告中描述的漏洞是否已被修复、具体方法论细节如何，源内容未予说明，读者需查阅原始报告确认。

Duncan Fyfe 在 Literary Hub 发表的随笔，考察英国小说家奥莉维亚·曼宁（Olivia Manning，1980 年去世）从真实生活中取材的写作习惯及其引发的后果。曼宁以取材于二战期间罗马尼亚和希腊经历的“巴尔干三部曲”最为知名，却终身未获布克奖短名单提名，生前抱怨自己从未得到应有的声誉。文章着重讲述 1967 年的一桩诽谤纠纷：罗马尼亚前总理阿拉曼德·克利内斯库（Armand Călinescu）的儿子、剑桥建筑师巴尔布·克利内斯库发现小说错误地声称其父遇刺后全家遭枪决，从而暗示他自己已死，遂要求出版商 Heinemann 和 Panther 撤销书籍并公开道歉，出版商最终以道歉、修改文本和偿付费用和解。《被毁坏的城市》（The Spoilt City）被召回修订，但平装本 Panther 初次处理不当，留下“被屠杀的克利内斯库一家”的复数指称，直到后来版本才更正——文中指出这一审查引入的错误约六十年未被人注意。

rss · Literary Hub · 11月4日 09:20

**「作家背景」** 奥利维亚·曼宁（Olivia Manning，1908–1980）是英国小说家，其最负盛名的“巴尔干三部曲”取材于她与丈夫在二战期间辗转罗马尼亚和希腊的亲身经历。她生前长期感到被文学界忽视：从未入围布克奖短名单、屡被拿来与艾丽丝·默多克比较而屈居其后，并渴望在世时获得认可。2010 年，纽约书评出版社（NYRB）将三部曲重版，由作家蕾切尔·卡斯克撰写序言，这部曾因诽谤纠纷被删改的作品才重新进入当代读者视野。

**「影响」** 巴尔干三部曲于 2010 年由 NYRB 再版，附蕾切尔·卡斯克撰写的推崇导言，使这位生前缺乏认可的小说家重新进入当代读者视野；不过卡斯克的导言未提及曼宁因这些小说卷入的诽谤风波——卡斯克本人也因回忆录《最后的晚餐》被读者认出而遭遇诉讼，其美国版被律师修改而受损。

### [伊兰·斯塔文斯谈文学翻译：冒名顶替者的自由](https://lithub.com/building-a-community-of-imposters-what-it-means-to-be-a-literary-translator-today/) ⭐️ 5.0/10

评论家、翻译家伊兰·斯塔文斯于 2026 年 11 月 4 日在 Literary Hub 发表书信体散文《Building a Community of Imposters: What It Means To Be a Literary Translator Today》,以给昔日学生 Miranda 回信的形式,探讨当今文学翻译者的处境。他的核心论点是:翻译本身就意味着“假托他人之声”,因此他更进一步为经典诗人“创作新的原作”——以阿赫玛托娃、塞兰、德拉蒙德、马拉美等人的口吻写诗,并宣称“文学冒名顶替并无羞耻,只有自由”。文章还援引贝克特翻译墨西哥诗歌\(收入奥克塔维奥·帕斯编选、1958 年出版的《墨西哥诗选》\)、理查德·威尔伯与厄休拉·勒古恩等不谙原语言仍从事翻译的先例,讨论译者对“内行合作者”或其他语言的依赖,以及人工智能在某些“异名”创作中的辅助作用。

rss · Literary Hub · 11月4日 09:20

**「背景」** 伊兰·斯坦斯（Ilan Stavans）是一位以文学翻译与批评著称的评论家，他在本文中以书信体形式回应昔日学生的提问，探讨文学翻译的本质。文章的核心论点是：翻译本身就意味着“化身为”他人之声，因此他更进一步，为阿赫玛托娃、佩索阿、马拉美等诗人创作“伪造的原作”，并援引贝克特翻译墨西哥诗歌（收录于奥克塔维奥·帕斯编纂、1958 年出版的《墨西哥诗选》）、理查德·威尔伯与厄休拉·勒古恩在不通晓源语言的情况下从事翻译等先例，论证“文学冒名”并非欺骗，而是一种自由。这一论述为译者与读者提供了一个关于翻译、模仿与作者身份边界的思辨文本。

**「影响」** 对译者和关注翻译的读者而言,这篇散文提供了一个讨论翻译伦理与创作边界的具体案例:当译者不再满足于转述而开始“伪造原作”,翻译的身份认同问题被推到了前台。文章的公开分享也可能促成更多关于人工智能介入翻译与创作实践的讨论。

### [Ry Herman 撰文：从酷儿童话传统中寻找创作灵感](https://lithub.com/ry-herman-on-finding-inspiration-in-queer-fairytales/) ⭐️ 4.0/10

作家 Ry Herman 在 LitHub 发表文章，讲述 2024 年夏天研究童话中 LGBTQ+内容的经历。作者发现 ATU 民间故事分类中编号 514 的“性别转换”类型包含数十个情节中带有明确酷儿元素的故事，如古希腊神话“伊菲斯与伊安忒”及北高加索纳特史诗中的“阿林贝格之女”，可追溯至数千年前。但作者指出，这些故事历经对酷儿不友善的时代流传后，变性结局常由诅咒等外力强加，目的只是让人物回到传统性别角色。文章节选自 Herman 的新作《This Knight Topples Empires》，该书由企鹅兰登书屋旗下 Dial Press 于 2026 年出版，小说以非二元性别主角 Jules 为叙事核心，回应作者对传统性别设定的质疑。

rss · Literary Hub · 11月4日 09:31

**「背景」** Ry Herman 是一位酷儿作家,本文节选自其 2026 年由 Dial Press\(Penguin Random House 旗下 Random House imprint\)出版的作品《This Knight Topples Empires》,属于配合新书出版的随笔。文章聚焦民间故事分类体系 Aarne-Thompson-Uther 索引中的 ATU 514 型&quot;变性&quot;故事,该类型包括源自北高加索纳特史诗和希腊神话&quot;伊菲斯与伊安忒&quot;等数千年的古老传说,赫尔曼以此作为其非二元性别主角创作的灵感来源。

**「影响与意义」** 这篇文章为读者提供了追溯 ATU 514 故事类型的线索，如塞尔维亚故事《女人变成男人》、芬兰故事《Satu》、智利童话《Florinda》和西班牙童话《独角兽的故事》，可能推动读者和创作者重新关注民间文学中的酷儿叙事传统；同时其附带的书籍信息表明，Dial Press 的新作已可通过常规渠道获取。
