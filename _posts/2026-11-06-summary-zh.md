### [Claude Code 被曝向网站发送用户邮箱地址](https://github.com/anthropics/claude-code/issues/107757) ⭐️ 7.0/10

有开发者报告称，Anthropic 的编程工具 Claude Code 在抓取网页时会把用户的邮箱地址发送给目标网站。社区分析指出，部分案例可能与 SEC 的 data.sec.gov API 有关——该 API 的文档要求在 User-Agent 请求头中包含邮箱地址，否则会拒绝请求。目前尚无 Anthropic 的完整官方说明，该问题已在 GitHub 上引发大量讨论。

hackernews · motoroco · 11月5日 22:17 · [社区讨论](https://news.ycombinator.com/item?id=50385272)

**「背景」** Claude Code 内置的网页抓取（web fetch）功能允许代理在执行任务时访问外部网站并读取内容，此前已有安全研究者指出，在处理不可信输入的环境中启用该工具存在数据外泄风险，建议仅在可信环境或非敏感数据场景下使用。本次报告的争议在于：工具在抓取网页时会将用户邮箱地址附带在请求中发出；社区分析认为部分情况源于美国证券交易委员会（SEC）数据 API 的硬性要求——其文档规定请求的 User-Agent 头必须包含邮箱，否则拒绝请求，因此该行为可能是为满足特定 API 规范，而非普遍性的隐私设计。

**「影响」** 有用户报告切换到 Claude Code 后工作邮箱收到的垃圾邮件明显增多，且邮件带有个性化姓名，说明邮箱泄露已产生实际骚扰后果。使用 Claude Code 进行网页抓取的开发者应注意邮箱可能暴露给所访问的网站，可考虑使用独立的邮箱地址。

**「社区讨论」** 用户 varenc 通过实测证实 SEC API 确实强制要求 User-Agent 中包含邮箱，认为部分行为是该服务的具体要求所致；也有评论者认为即便邮箱不算高敏感信息，Anthropic 仍需建立对外发送信息的监控机制。另有用户列举了多个相关 GitHub issue，认为这并非孤立问题。
