### [llama.cpp 发布 v1.0.0：为本地 AI 生态确立稳定 API 基础](https://huggingface.co/blog/ggml-org/llama-cpp-v1) ⭐️ 7.0/10

llama.cpp 与底层张量库 ggml 正式发布 v1.0.0 库版本，标志着项目在成立约 3.5 年后首次对下游开发者承诺稳定的公共 C API/ABI。从该版本起，ggml-org 项目采用语义化版本规则：./include 中公共 C API 的不兼容变更将触发主版本号递增，向后兼容的功能、后端更新或新模型支持为次版本，纯修复为补丁版本。发布物覆盖 Linux、macOS、Windows、Android、iOS 等平台的预构建产物，以及 Docker、Debian、Homebrew、conda-forge、Winget、XCFramework 等分发渠道。项目目前支持超过 150 种模型架构变体及主流投机解码方法，CI 由 Hugging Face 的 HF Buckets/HF Jobs 以及 NVIDIA、AMD、Qualcomm、Arm、IBM、Intel 提供的自托管硬件支撑。

rss · Hugging Face Blog · 11月13日 14:05

**「背景」** llama.cpp 是一个用 C/C++ 编写的开源推理项目,自 2022 年发布以来,通过量化技术和可移植的 ggml 张量库,使大语言模型能够在从消费级设备到企业服务器的广泛硬件上运行,并逐渐成为大量本地 AI 应用和下游项目依赖的基础库。在此之前,该项目从未标记过 1.0.0 稳定版本,库接口\(如 libllama 和 libggml 的公开 C API\)在开发过程中可能发生不兼容变更,下游开发者需要自行跟进接口变动。

**「影响」** 对基于 libllama/libggml 构建本地推理应用的开发者而言，v1.0.0 意味着 API 与 ABI 的不兼容变更从此会以主版本号显式可见，可以将升级决策建立在明确的语义化版本约定上，而不是跟踪 master 分支的不确定变动；同时打包方现在可以通过官方列出的渠道（如 Homebrew、conda-forge、Winget、Debian）集成 ggml-org 软件，集成流程有了正式入口。

2026 年 11 月 13 日下午，美国联邦航空管理局（FAA）下令全国范围内暂停所有美国机场的离港航班，这是美国历史上第三次全国性停飞。交通部长 Sean Duffy 在 X 上表示，原因是影响所有航路交通管制中心的&quot;通信问题&quot;，FAA 正在排查；国土安全部部长 Markwayne Mullin 称这是 FAA 的电信网络故障，目前没有迹象表明存在恶意攻击，并将对入境国际航班逐一处置。据报道，故障涉及由 L3Harris 运营、承载管制员与飞行员无线电通信的电信网络，但原因尚未确认，雷达数据是否受影响也不明确。

### [Windows SignDrop 零日漏洞公开：普通用户可提权至 System 权限](https://arstechnica.com/security/2026/11/windows-0-day-dropped-by-disgruntled-researcher-hands-hackers-system-rights/) ⭐️ 7.0/10
