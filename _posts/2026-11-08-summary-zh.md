### [Coldframe：伪装成超市冷柜控制器的开源蜜罐](https://github.com/hedgerow-dev/coldframe) ⭐️ 7.0/10

开发者 hedgerow-dev 发布了 Coldframe，一个单文件、仅使用 Python 标准库的开源蜜罐，可逼真伪装成 Danfoss AK-SM 800A 和 Dixell XWEB 超市制冷控制器。作者参照 Shodan 上真实设备的记录匹配了 HTTP 头顺序、页面标题、证书字段和 TLS 版本（例如 Dixell 页面精确填充到 8,202 字节），使其在 Shodan 上被识别为真实设备。它还能识别 CVE-2025-41450（Danfoss&quot;当日口令&quot;登录绕过）等漏洞的利用尝试，并允许默认凭据登录进入一个虚假的商店仪表盘，以观察攻击者的后续动作。作者部署的两个实例已运行一天，目前只收到通用扫描和 Shodan 爬虫的访问。

hackernews · hedgerow-dev · 11月7日 17:27 · [社区讨论](https://news.ycombinator.com/item?id=50406292)

**「背景」** Coldframe 模仿的是 Danfoss AK-SM 800A 和 Dixell XWEB 两款超市冷藏控制器,其中 Danfoss 平台曾于 2025 年 3 月被官方确认存在身份认证绕过漏洞\(AK-SM8xxA 系列,补丁 4.2 修复\),对应 CVE-2025-41450 &quot;每日口令&quot; 登录绕过,这正是该蜜罐能够识别的攻击之一。Danfoss 控制器嵌入 Web 管理界面的多个漏洞此前也由 Claroty Team82 等安全研究团队公开披露,Coldframe 作者明确表示其项目建立在 Synacktiv、Claroty 和 Ironhackers 的公开研究基础之上。

**「影响」** 安全研究人员可以用它低成本观察针对工业制冷系统的真实攻击行为；但作者在讨论中指出，超市通常没有安全团队，这类设备的补丁、VPN 和强密码保护只能依赖厂商或安装方默认提供，否则难以落地。

**「社区讨论」** 用户 supriyo-biswas 提醒，Shodan 上的数据不可全信——他自己复刻 Wi-Fi 摄像头时发现网上多数&quot;真实&quot;设备其实已是蜜罐或被入侵的机器，建议作者用真实易受攻击的设备做对照。另有用户 xrd 质疑近期针对制冷设备的大规模入侵事件是否属实，指出可能只是批量软件更新造成的误会，尚无定论。

### [Alex Stamos 谈 AI 攻击浪潮如何颠覆网络安全行业](https://www.theverge.com/podcast/1029038/ai-cybersecurity-hackers-data-breach-dark-age-alex-stamos) ⭐️ 7.0/10

The Verge 的 Decoder 播客发布了对 Cognition 首席安全官 Alex Stamos 的访谈（该节目为“AI 现实应用”专题系列的第一部分），他认为数十亿美元规模的网络安全行业正被 AI 加持的攻击浪潮压垮。他举例称，一家 AI 服务商 Fireworks 被攻破后，攻击者窃取 API 密钥进入 Cursor，随后推送恶意插件波及约 5000 家公司；此外还有针对三星银行的攻击，本周约 200 家公司遭殃。他特别指出，中国开源工具 ARTEX 配合开放权重模型可实时发现漏洞并编写利用代码，从而自动化攻击链的大部分环节。Stamos 并非长期悲观，但认为行业在适应新时代前将经历一段“黑暗时代”。

rss · The Verge · 11月7日 15:00

**「背景」** 要理解这期节目的核心论点,需要先了解传统网络攻击的流程:攻击者通常要提前完成漏洞研究、编写利用代码等大量准备工作,再由人工部署到目标系统,这一系列步骤在安全行业被称为&quot;杀伤链&quot;\(kill chain\)。Alex Stamos 在访谈中提出的判断是,开源权重模型已经发展到可以自动化大部分杀伤链的程度——他举例提到中国开源工具 ARTEX 可在运行时实时发现漏洞并生成利用代码,这使攻击的门槛和成本大幅降低。此外,他提到近期的 PHP、Node 等重大漏洞,以及 Fireworks API 密钥失窃后连锁导致 Cursor 被入侵并波及约 5000 家公司的事件,说明这些 AI 增强的攻击已开始以链式方式扩散,这正是他认为行业正进入&quot;黑暗时代&quot;的语境。

**「影响」** 由于攻击链已被 AI 工具实时自动化，此前依赖预先研究漏洞、再由人工定向部署的防御假设不再成立，企业（尤其是依赖 AI 服务商和云平台的公司）面临被供应链式攻击连锁波及的风险。安全团队应重新审视 API 密钥等凭证的权限范围，并对第三方插件与依赖的分发渠道保持警惕。

### [鲁宾天文台在早期观测中发现两个此前未知的银河系伴星系统](https://www.sciencedaily.com/releases/2026/11/261104012252.htm) ⭐️ 7.0/10

薇拉·鲁宾天文台利用仅覆盖约 7%夜空的初步观测数据,发现了两个此前未知的银河系伴星系统:一个距离约 35.5 万光年的极暗弱星系,以及一个隐藏在宇宙尘埃背后的星团。这些发现来自该台巡天早期阶段的数据,尚属初步结果,两个天体的详细物理性质\(如恒星族群、金属丰度和暗物质含量\)还未得到表征。科学家估计银河系可能还有数百个未被发现的卫星星系,鲁宾望远镜的深度和广域巡天能力有望将它们陆续揭示。

rss · ScienceDaily Astronomy · 11月7日 09:12

**「背景」** 银河系的暗弱伴星系（尤其是超暗矮星系）几乎完全由暗物质主导，亮度极低且常被银河系尘埃遮挡，因此此前的巡天只发现了其中一小部分。标准宇宙学模型预测银河系周围应存在数百个此类卫星星系，而探测数量与模型预测之间的差异一直是观测宇宙学的重要议题。薇拉·鲁宾天文台凭借大视场和深巡天能力，正在系统性地补齐这部分缺失的卫星星系样本。

**「观测与理论意义」** 仅在巡天 7%的天区就找到两个新的暗弱伴星系统,意味着暗弱卫星星系的实际数量可能远超现有巡天记录,这为限制卫星星系数量分布和暗物质小尺度结构模型提供了新的观测约束,后续巡天数据释放将检验ΛCDM 模型对卫星星系群体的预言。

rss · NASA News Releases · 11月7日 22:47

### [丹麦埃斯比约海水热泵冬季实测：19.9 兆瓦电产 55.2 兆瓦区域供热](https://cleantechnica.com/2026/11/07/esbjerg-seawater-heat-pumps-cold-water-district-heating/) ⭐️ 7.0/10

丹麦埃斯比约（Esbjerg）已投运大型海水源热泵，从北海海水中取热供应城市区域供热网。在一次两小时冬季测试中，海水以 3.3°C 进入系统、以 1.2°C 排出，两台热泵消耗 19.9 兆瓦电力并输出 55.2 兆瓦热量，对应约 2.8 的性能系数（COP）。该数据来自单次短期测试，长期运行性能仍有待验证。

rss · CleanTechnica · 11月7日 17:21

**「背景」** 海水源热泵是大型热泵的一种应用形式,即便在冬季低温海水\(本次为 3.3°C\)条件下,也能通过蒸发器从海水中提取低品位热量,再经压缩升温后供应区域供热管网。丹麦的区域供热系统以低温热水管网为基础,配合绿电驱动的大型热泵,是用清洁热源替代化石燃料锅炉、实现供热系统电气化脱碳的主要路径之一;埃斯比约项目即属于此类已投运的大型海水热泵供热设施。

**「影响」** 这一实测结果证明，即便冬季海水温度低至 3.3°C，大型热泵仍能经济地从中提取热量，为低温区域供热的电气化脱碳提供了可复制的运行依据；按该 COP 水平，每兆瓦时电力可产出约 2.8 兆瓦时热量，有助于在电力系统脱碳的同时降低供热网的化石燃料依赖。
